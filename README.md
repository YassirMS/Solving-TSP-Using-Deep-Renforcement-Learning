# Solving-TSP-Using-Deep-Renforcement-Learning
Traveling Salesman's Problem is a well know Operational Reasearch Problem, that is NP-hard. Multiple exact solvers exist such as CONCORDE [https://www.math.uwaterloo.ca/tsp/concorde.html].
Recently, Deep Reinforcement learning methods are gaining more momentum, especially applied to local search methods such as in l2i[H. Lu, X. Zhang, S. Yang. A Learning-based Iterative Method for Solving Vehicle Routing Problems. International Conference on Learning Representations (ICLR), 2020.] or l2gls[N. Sultana, J. Chan, B. Abbasi, T. Sarwar, A. K. Qin. Learning to Guide Local Search Optimisation for Routing Problems. Operations Research Letters, 55 :107136, 2024.] because of their capacity to solve such problems in significanty lower time, and competitive GAP. 
# Additional Value of this project
In this project, we will do an implementation of the l2gls methods and try to improve the solutions through a comparative approach using : DQN (Deep-Q Network), REINFORCE and PPO.
